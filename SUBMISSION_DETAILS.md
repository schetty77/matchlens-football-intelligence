## Description
MatchLens turns a reproducible stream of synthetic football events into evidence-backed match intelligence. It replays a match, calculates verified score and expected-goals metrics, and uses deterministic Python rules to detect turning points without guessing.

Every insight links directly to the event IDs and metrics behind it. Fan mode tells a clear match story; Analyst mode exposes the supporting sequence and numbers. A grounded full-time recap uses the same verified data. MatchLens is built for broadcasters and digital match experiences that need to explain *why* a moment mattered, not merely report what happened. It uses synthetic football-realistic data only, and its source and demo assets are hosted in a public GitHub repository.
